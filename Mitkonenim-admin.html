    • Live installs: goes up by one the moment an install arrives; counts the current local day and starts again at midnight.
    • Total installs: every install ever recorded. A retried event is never counted twice.
    • Active users: distinct users with more than 2 logins in the rolling last 7 days. Someone with only 1 or 2 logins is not "active" yet but is included in the "logged in at least once" figure under the tile.
    • PC / iOS / Android: active users on each kind of device, based on where they logged in. PC = Windows, Mac, Linux. iOS = iPhone and iPad. Swipe left or right, or tap a tab, to switch. Each user is shown by their personal code with a device badge.
